metadata:
  type: feedback
---

커밋과 푸시는 사용자가 "커밋 푸시해줘" 등 명시적으로 요청할 때만 실행한다. 작업 완료 후 "커밋할까요?" 같은 확인 질문도 하지 않는다.

**Why:** 사용자가 커밋 타이밍을 직접 통제하고 싶어함. 질문도 불필요하다고 명시함.

**How to apply:** 코드 수정 완료 후 커밋/푸시 관련 언급 일절 하지 않는다. 사용자가 요청할 때 확인 없이 바로 실행한다.
